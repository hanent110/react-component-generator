# PR 본문 템플릿 (kr)

아래 코드 블록의 구조와 순서를 그대로 유지하고 내용만 채운다.

```markdown
## 요약

<!-- 이 PR이 무엇을 왜 바꾸는지 1~3문장 -->

## 변경 사항

<!-- 핵심 변경을 목록으로. 파일 나열이 아니라 동작·구조 단위로 -->

-

## 변경 이유

<!-- 배경, 해결하려는 문제, 이 방식을 택한 이유 -->

## 테스트

<!-- 실행한 것만 적는다. 실행하지 않았으면 "미실행"과 사유 -->

- [ ] 테스트:
- [ ] 린트:
- [ ] 빌드:
- [ ] 수동 확인:

## 리뷰어 참고

<!-- 중점적으로 볼 부분, 알려진 한계, 후속 작업. 없으면 "해당 없음" -->
```
